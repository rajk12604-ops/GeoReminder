# GeoReminder 📍

## About the App
GeoReminder is an Android application that helps users set location-based reminders. It reminds users when they reach or leave a particular location.

## App Name
GeoReminder

## Technologies Used
- Java / Kotlin
- XML
- Android Studio
- Gradle

## Features
- Location-based reminders
- Easy-to-use interface
- Smart location notifications
- Simple and user-friendly design

## Requirements
- Android Studio
- Android SDK
- Gradle
- Location permission

## How to Run
1. Clone or download this repository.
2. Open the project in Android Studio.
3. Wait for Gradle Sync.
4. Run the app on an emulator or Android device.
